# 售价筛选

在「引路石」和「石板」页签内的「售价筛选」区域选择币种及至多、区间或至少，生成用于 PoE2 游戏内仓库／商店搜索框的价格备注正则。售价与当前页签的其他条件同时生效，统一显示在「已选条件」并复制同一条正则。该功能按挂牌售价定位物品，不查询行情，不换算币种。

## 使用规则

- 支持崇高石、神圣石、混沌石，只匹配 `~b/o`。
- 只接受正整数，区间包含两端；上下限相等即为精确价格。
- 区间留空一端表示不设该端限制；两端都为空时不生成。
- 小数、负数、零、非数字、超过 JavaScript 安全整数范围的数值，以及上下限倒置均不生效，原输入保留并提示原因。不自动取整或交换上下限。
- 不匹配比例标价，如 `~b/o 1/10 exalted`。
- 两个页签各自保存售价，并与原条件一起保存到收藏。售价区域的「清除」只清除当前页签售价；右侧清空则清除当前页签全部筛选，不影响另一页签。
- 复制筛选链接可在另一浏览器恢复当前页签、语言及全部条件；随后修改再刷新时使用修改后的条件。导入链接不覆盖另一页签或已有收藏。旧独立售价设置和旧售价链接迁移到当前页签。
- 售价输入有误时仅停用售价并就地提示，其他有效条件仍能生成和复制；没有任何有效条件时不可复制。
- 简中、繁中、英文界面共用相同的备注表达式。

## 生成与字符预算

数值生成器独立于现有词缀引擎，不使用其 999 上限或放宽匹配策略。它按位拆分区间，合并相同后缀的数字集合、提取公共前缀，并在等价写法中选择更短者。生成成本随输入位数变化，不逐个枚举价格。

数字后保留空格和币种片段，避免把 100 误认为 1。正常游戏备注中的币种片段为 `ex`、`div`、`chaos`，分别匹配 `exalted`、`divine`、`chaos`。

例如：

| 条件 | 输出 | 字符数（含引号） |
|---|---|---|
| 1～2 神圣石 | `"~b/o [12] div"` | 15 |
| 1～10 崇高石 | `"~b/o ([1-9]\|10) ex"` | 20 |

输出区统一显示完整组合正则的字符数及 250 字符预算，分隔空格和引号同样计入；售价区域不重复显示统计。售价作为必选条件与基础筛选、阶级、效果及词缀相交；词缀选择「满足任一」时，售价仍必须满足。

售价子模块显示「币种」「筛选方式」分组小标题、上下限及「清除」，宽屏同行排列并对齐小标题、窄屏自动换行。输入规则保留在标题悬停提示和辅助说明中，无效输入时才显示错误。复制完整筛选链接的入口位于统一结果区。

存在有效售价时仅使用精确条件，不启用原词缀引擎的放宽拟合；超过预算时保留完整表达式供查看，但禁止复制正则或分享链接，不截断、不放宽范围。

## 开发和验证

保持单 HTML 文件直接运行：独立数值引擎负责售价区间，页面控制接入现有页签状态、组合生成、收藏及复制流程，不引入运行时依赖。

实施顺序：整数范围压缩 → 页签内筛选区域 → 组合生成和防呆 → 保存／收藏／分享 → 数值与浏览器验证。

```text
node tests/stash-price.cjs
python tests/stash-price-browser.py
```

第二项需要已安装 Python Playwright 和 Chrome；运行独立无头浏览器及本机临时 HTTP 服务。截图存放于本地项目记忆目录，不随功能提交。

数值测试覆盖小区间穷举、跨位数大区间、千位以上、无上限模式、安全整数边界、错误输入、币种和字符预算；同时检查所有内嵌脚本语法及原引擎自检。浏览器测试覆盖两个页签的独立设置、售价与阶级/类型/词缀相交、词缀任一模式、无效售价保留其他条件、收藏、三语、真实剪贴板、完整分享恢复及编辑后刷新、旧独立设置迁移、手机宽度、存储不可用，以及组合超长时禁止复制而不放宽。

游戏内已由用户确认 `~b/o` 有效，并明确本功能按整数售价设计。本次数值与浏览器测试不等同于完整游戏内验证。
